# SIMS ARCHIVE

SIMS ARCHIVE is a personal web application for organizing and managing The Sims 4 mods and custom content.

## Features

- Manage The Sims 4 mods and custom content
- Track installed and used mods
- Organize mods by type and folder
- Track the current The Sims 4 game version
- Check for game and mod updates

## CurseForge Integration

CurseForge API integration is planned for checking whether mods saved in the personal library have newer releases available.

The application does not redistribute, re-host, or automatically download CurseForge files.
